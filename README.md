# 👑 SN BUMP

Bot avanzado de bump para Discord con sistemas de configuración, estadísticas y administración.

## ✨ Características

・🚀 Sistema de Bump
・⚙️ Configuración personalizada por servidor
・📊 Estadísticas del servidor
・🏆 Ranking de servidores
・📝 Sistema de logs
・🚫 Sistema de blacklist
・🔔 Recordatorios de bump
・📌 Plantillas de promoción
・💾 Base de datos integrada
・🌐 Servidor web para mantener el bot activo

## 📜 Comandos

### 📢 Bump
`/bump`
> Envía la promoción configurada.

`/plantilla-bump`
> Configura el mensaje de promoción.

`/cooldown`
> Cambia el tiempo de espera del bump.

### ⚙️ Configuración

`/config`
> Muestra la configuración actual.

`/logs`
> Configura el canal de logs.

`/recordatorio`
> Activa o desactiva avisos de bump.

`/rol-bump`
> Configura el rol autorizado para usar bump.

### 📊 Información

`/stats`
> Muestra estadísticas del bot.

`/ranking`
> Muestra los servidores con más bumps.

`/ping`
> Muestra la latencia del bot.

`/invite`
> Muestra el enlace de invitación.

`/help`
> Muestra la ayuda del bot.

`/guia`
> Guía rápida de uso.

### 🛡️ Administración

`/blacklist`
> Añade un servidor a la lista negra.

`/unblacklist`
> Quita un servidor de la lista negra.
