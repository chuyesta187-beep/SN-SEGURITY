# 🚀 SN Bump AI

SN Bump AI es un bot de Discord desarrollado con Discord.js v14 que permite promocionar servidores mediante un sistema de bump global.

## ✨ Funciones

- 🚀 Sistema de Bump Global
- 📊 Estadísticas
- 🏆 Ranking de servidores
- 🎨 Embeds personalizables
- 🔔 Recordatorios automáticos
- 📝 Sistema de logs
- 🚫 Blacklist
- 📖 Panel de ayuda interactivo

## 📦 Requisitos

- Node.js 20 o superior
- Un bot de Discord
- API Key de Gemini

## ⚙️ Variables de entorno

Crea un archivo `.env` con:

```env
DISCORD_TOKEN=
CLIENT_ID=
GEMINI_API_KEY=
```
