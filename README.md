🛡️ SN SECURITY v6.0

SN SECURITY es un bot avanzado de seguridad para Discord desarrollado para STEAL NATION.

✨ Características

- 🛡️ AutoMod
- 🚨 AntiRaid
- 🔥 AntiNuke
- 📜 Logs completos
- 👮 Sistema de Staff
- 🎫 Sistema de Apelaciones
- 💾 Base de datos SQLite
- 🌐 Compatible con Render
- ⚡ Comandos Slash
- 📊 Sistema de advertencias (Warns)

📦 Requisitos

- Node.js 22 o superior
- Discord.js v14
- Better SQLite3
- Express

🚀 Instalación

npm install

▶️ Iniciar el bot

npm start

🔑 Variables de entorno

Configura estas variables antes de iniciar el bot:

- "DISCORD_TOKEN"
- "PORT"
